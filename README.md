# SQL-Hospital-Data-Analysis
A beginner-friendly SQL portfolio project built with PostgreSQL, demonstrating data import, database design, analytical SQL queries, and healthcare data reporting.


# 🏥 SQL Hospital Data Analysis

This project is part of the **30 Days SQL Micro Course Assignment**.

## Project Overview

The project demonstrates SQL skills by analysing hospital data using PostgreSQL and pgAdmin.

## Tools Used

- PostgreSQL
- pgAdmin 4
- SQL

## Dataset

Hospital_Data.csv

## Database Schema

The database contains one table:

hospital_data

Columns:

- Hospital Name
- Location
- Department
- Doctors Count
- Patients Count
- Admission Date
- Discharge Date
- Medical Expenses

## SQL Concepts Used

- CREATE TABLE
- Aggregate Functions
- GROUP BY
- ORDER BY
- LIMIT
- AVG()
- SUM()
- Date Functions

## Assignment Questions Solved

✔ Total Number of Patients

✔ Average Number of Doctors per Hospital

✔ Top 3 Departments with Highest Patients

✔ Hospital with Maximum Medical Expenses

✔ Daily Average Medical Expenses

✔ Longest Hospital Stay

✔ Total Patients per City

✔ Average Stay per Department

✔ Department with Lowest Patients

✔ Monthly Medical Expenses Report
